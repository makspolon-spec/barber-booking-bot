# Barber Booking Bot

Telegram-бот онлайн-записи для барбера. Клиент выбирает услугу и свободное время кнопками, мастер подтверждает запись в один клик, а бот сам напоминает клиенту о визите.

## Что умеет

- Главное меню: запись, услуги, цены, контакты
- Запись на свободное время кнопками (занятые слоты скрываются, двойная запись невозможна)
- Хранение записей в базе данных SQLite
- Мастер подтверждает или отклоняет запись кнопкой прямо в заявке
- Клиент получает уведомление о решении мастера
- Автонапоминания клиенту за сутки и за час до визита
- Команда /bookings со списком ближайших записей (только для мастера)

## Технологии

- Python 3
- [aiogram 3](https://docs.aiogram.dev/)
- SQLite
- FSM (машина состояний) для диалога с клиентом

## Как запустить

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости: `pip install -r requirements.txt`
3. Задайте переменные окружения: `BOT_TOKEN` (токен от BotFather), `OWNER_ID` (Telegram ID мастера, его можно узнать командой /id) и при необходимости `TIMEZONE` (по умолчанию Europe/Kyiv).
4. Запустите: `python bot_v2.py`

## Как настроить под своего клиента

- Услуги: список `SERVICES` в начале файла
- Рабочие часы: список `SLOTS`
- Цены, адрес и график работы: обработчики «Цены» и «Контакты»
- Получатель заявок: переменная `OWNER_ID`

Настройка под конкретный бизнес занимает 1-2 часа.
