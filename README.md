
# Barber Booking Bot

Telegram-бот для записи клиентов к барберу. Клиент выбирает услугу и время прямо в Telegram, а мастер сразу получает заявку в личные сообщения.

## Что умеет

- Главное меню: запись, услуги, цены, контакты
- Пошаговая запись: услуга → дата и время → имя и телефон
- Заявка мгновенно приходит владельцу в Telegram
- Кнопка отмены на любом шаге записи

## Технологии

- Python 3
- [aiogram 3](https://docs.aiogram.dev/) (библиотека для Telegram-ботов)
- FSM (машина состояний) для пошагового диалога

## Как запустить

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимость: `pip install aiogram`
3. Передайте токен через переменную окружения `BOT_TOKEN` (в коде токена нет).
4. Узнайте свой Telegram ID: запустите бота и отправьте ему `/id`.
5. Впишите ID в `OWNER_ID` в файле `bot.py`: туда будут приходить заявки.
6. Запустите: `python bot.py`

## Как настроить под своего клиента

- Услуги и цены: тексты в обработчиках «Услуги» и «Цены» и кнопки в `services_kb`
- Контакты и график работы: обработчик «Контакты»
- Получатель заявок: `OWNER_ID`

Настройка под конкретный бизнес занимает 1-2 часа.
